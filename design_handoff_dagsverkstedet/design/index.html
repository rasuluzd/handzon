Spesifikasjonene ligger ett nivå opp

  • README.md — start her. Seks PR-er i rekkefølge
  • TOKENS.md — hver token med hex og Tailwind-klasse
  • COMPONENTS.md — anatomi og tilstander per primitiv
  • SCREENS.md — kundeflaten skjerm for skjerm
  • ADMIN.md — adminpanelet skjerm for skjerm
  • MOTION.md — hver animasjon med varighet og utløser
  • CONTENT.md — språkregler med eksempler
  • code/ — ferdig TypeScript, lim inn direkte

Prototypene er designreferanser, ikke produksjonskode. De kjører på plain React + Babel i nettleseren uten byggesteg. Bruk dem til å se utseende, tilstander og oppførsel — hent verdiene fra TOKENS.md og COMPONENTS.md.
